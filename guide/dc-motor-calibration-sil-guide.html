Week 4 · DC Motor

CALIBRATION을 제어 로직으로 옮기고 SIL로 검증하기

모터 레지스터를 직접 만지는 코드와, 그 함수를 호출해 동작 순서를 결정하는 코드를 분리합니다. 같은 제어 로직을 가상 모터에서 먼저 검증한 뒤 MCU 예제에 연결합니다.

1. 과제 정의

  • 초기 위치는 1000으로 시작합니다.
  • CCW Hall pulse는 현재 위치에 +1, CW Hall pulse는 -1을 반영합니다.
  • CALIBRATION 명령을 받으면 CCW로 END POINT에 닿을 때까지 이동하고, 이어서 CW로 START POINT에 닿을 때까지 이동합니다.
  • 목표 위치는 START + (END - START) * percent / 100입니다. GET_ON=50%, GET_OFF=10%입니다.

2. 동작 순서

01초기화current_position = 1000
02CALIBRATIONCCW 이동 → END 저장 → CW 이동 → START 저장
03GET_OFFSTART에서 END 방향으로 10% 이동
04검증변수 출력과 종료 코드로 성공 판정

3. 반드시 나눌 두 영역

펌웨어 / 하드웨어FW_Motor_SetCCW, FW_Motor_SetCW, FW_Motor_Stop, ADC, UART, EXTI, PWM 초기화처럼 레지스터를 직접 제어합니다.
제어 로직CL_StartCalibration, CL_HandleCalibration, CL_StartMove처럼 상태와 위치를 계산하고 펌웨어 함수를 호출합니다.

SIL에는 첫 번째 영역 대신 sil_environment의 가상 모터·Stopper·Hall callback이 들어갑니다. 따라서 제어 로직에 레지스터가 섞이면 SIL에서 재사용할 수 없습니다.

4. 로컬 SIL 판정

sil/run-sil.bat       # Windows
sil/run-sil.sh        # Linux/macOS/Git Bash

calibration_complete=1
start_point=980
end_point=1020
current_position=984
target_position=984
success=1

프로그램은 CALIBRATION → GET_OFF을 자동 실행합니다. success=1이 출력되고 프로세스 종료 코드가 0이면 통과입니다.
