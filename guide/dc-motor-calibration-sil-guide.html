Week 4 · DC Motor

CALIBRATION을 제어 로직으로 옮기고 SIL로 검증하기

모터 레지스터를 직접 만지는 코드와, 그 함수를 호출해 동작 순서를 결정하는 코드를 분리합니다. 같은 제어 로직을 가상 모터에서 먼저 검증한 뒤 MCU 예제에 연결합니다.

1. 과제 정의

  • 초기 위치는 1000으로 시작합니다.
  • IMS 좌표는 LOWER=0, UPPER=전체 stroke이며, CW Hall pulse는 +1, CCW Hall pulse는 -1을 반영합니다.
  • CALIBRATION 명령을 받으면 CW로 UPPER에 닿은 뒤 CCW로 LOWER까지 이동하고, LOWER=0, UPPER=stroke로 저장합니다.
  • 목표 위치는 LOWER + (UPPER - LOWER) * percent / 100입니다. GET_ON=50%, GET_OFF=10%입니다.

2. 동작 순서

01초기화current_position = 1000
02CALIBRATIONCW → UPPER 확인 → CCW → LOWER 확인 → LOWER=0 저장
03GET_OFF / GET_ON10% / 50% 목표 위치로 이동
04STOP현재 위치에서 모터 정지
05검증변수 출력과 종료 코드로 성공 판정

3. common과 실행 환경 분리

common / ASWcommon/dc_motor_control.c/.h. 명령, 상태, LOWER/UPPER 좌표와 목표 위치만 계산하며 MCU 레지스터를 사용하지 않습니다. 학생 제출 영역입니다.
target / 실제 MCUtarget/dc_motor_target.c. GPIO, TIM2, ADC1, USART1, EXTI6, Hall 레지스터와 실제 callback을 구현합니다. 고정 제공 영역입니다.
sil / PC 검증sil/sil_environment.c/.h. 실제 모터·Hall·Stopper 대신 가상 callback을 구현합니다. 고정 제공 영역입니다.
reference / 사이트reference/dc_motor_reference.c. 사이트에 붙여 넣기 쉽도록 FW와 제어 로직을 한 파일 안에서 구분한 통합 예제입니다.

common/은 target과 SIL에서 그대로 재사용됩니다. 학생 코드에 레지스터가 섞이면 실제 환경과 SIL을 같은 코드로 검증할 수 없습니다.

4. 로컬 SIL 판정

sil/run-sil.bat       # Windows
sil/run-sil.sh        # Linux/macOS/Git Bash

calibration_complete=1
start_point=0
end_point=100
current_position=49
target_position=10
calibration_test=1
get_off_test=1
get_on_test=1
stop_test=1
success=1

프로그램은 CALIBRATION → GET_OFF → GET_ON → STOP을 자동 실행합니다. 네 테스트가 모두 1이고 success=1이 출력되며 프로세스 종료 코드가 0이면 통과입니다.
